# sumshining-media

인스타그램 @sum.shining (썸샤이닝) **전용** 공개 저장소. 다른 프로젝트의 파일은 두지 않는다.

| 경로 | 내용 |
|---|---|
| `index.html` | 프로필 링크용 랜딩 페이지 (반짝 #N 상품 링크 모음, GitHub Pages) |
| `posts/<게시물번호>/` | 사용자 승인을 받은 게시물의 이미지(.jpg)·영상(.mp4) — 인스타그램 API 가 공개 URL 로 가져감 |

코드·설정·키·리포트는 이 저장소에 두지 않는다(허용 목록 + 커밋 전 검사로 차단).
